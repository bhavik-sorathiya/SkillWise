# SkillWise Documentation

This folder contains the canonical project documentation in a fixed structure.

## Document Map
- `docs/architecture.md`: System architecture, data flow, interaction diagrams
- `docs/backend.md`: Backend folder structure, services/controllers, business logic
- `docs/api.md`: REST endpoints, auth model, request/response examples, socket events
- `docs/database.md`: Database schema, relationships, and key SQL queries
- `docs/deployment.md`: Environment setup, build/run steps, deployment guidance
- `docs/getting-started.md`: Local setup, project walkthrough, pitfalls, reading order
- `docs/tech-stack.md`: Technologies, why they are used, and where they are used
- `docs/decisions.md`: Architectural decisions and trade-offs

## Scope
These docs cover:
- Frontend (`client/`)
- Backend (`server/`)
- MySQL schema (`dbQueries.sql`)
- Real-time interview flow (Socket.IO)

## Versioning Note
When architecture, API contracts, or schema changes, update these docs in the same pull request.
